# To-Do List Application

## 📖 Description
Une application simple de gestion de tâches en ligne de commande. Vous pouvez :
- Ajouter des tâches.
- Marquer des tâches comme terminées.
- Supprimer des tâches.
- Visualiser la liste des tâches en cours et terminées.

Ce projet est conçu pour vous initier à la contribution open source en Python.
